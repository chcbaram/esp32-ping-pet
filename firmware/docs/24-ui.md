# 24. UI — Ping Pet 대시보드와 답답이

> 목업(Slack 다마고치 UI 캔버스)을 LVGL 로 옮긴다. 런처 · 테마는 `~/hdd/git/HG-T113-S3`, LVGL 포팅은 [23](23-lvgl.md).
> 관련: [22](22-lcd-touch.md) (화면 좌표, 터치), 인계 문서 "보드 펌웨어 사양", "UI와 캐릭터"
>
> **상태: 보드에서 확인 (2026-10-10).** 데모 모드로 4 상태, 글자 크기 3 단계, 설정 앱, 캐릭터 애니메이션. 맥 중계 연결은 아직.

## 1. 구조

```
ap/modules/
├── inbox/
│   ├── inbox.c / inbox.h      미응답 목록 모델 (MODULE_DEF, 우선순위 4)
│   └── inbox_demo.c           데모 모드
└── ui/
    ├── ui.c / ui.h            MODULE_DEF(ui), "ui" 태스크에서 런처 + LVGL, ui CLI
    ├── ui_theme.c / .h        팔레트, 간격, uiFont() / uiFontPixel(), 글자 크기 · 밝기
    ├── app.h                  APP_DEF (constructor 등록)
    ├── launcher/launcher.c    app 띄우기 · 거두기, 전원을 켜면 Ping Pet 바로
    ├── app/pingpet/           pingpet.c (대시보드), pet.c (답답이)
    ├── app/settings/          settings.c
    └── fonts/                 Jua · Silkscreen TTF + OFL (fonts 파티션으로 굽는다)
```

```
맥 중계 (예정) ─┐
                ├─▶ inbox (잠금) ──스냅숏──▶ pingpet (ui 태스크, 0.2 초마다)
데모 모드 ──────┘                              │
                                               ├─ 목록 · 상태가 바뀌면 : 오른쪽 패널 다시 만들기
                                               └─ 매번 : 시계, 요약, 배부름, 카드 경과 시간
```

- **화면은 inbox 스냅숏(`inboxGetView`)만 읽는다.** 데모와 맥 중계가 같은 함수로 넣으므로 데모 화면이 곧 실제 화면이다
- **LVGL 은 ui 태스크에서만 부른다.** cli 등 다른 태스크는 요청만 남긴다 — `launcherRequestApp()`, `inboxDemoSet()`
- 화면을 누르는 동안은 오른쪽 패널을 다시 만들지 않는다. 누르던 카드가 지워지면 1 초 길게 누르기가 끊긴다

### 런처 (HG-T113-S3 의 뼈대)

`APP_DEF` 로 자기 등록하는 app 구조와 컨테이너를 겹치는 화면 구조만 가져왔다. 홈 그리드 · 아래 가장자리 제스처 · 오버레이는 app 이 늘면 가져온다.
**전원을 켜면 홈 없이 `UI_APP_DEFAULT`("pingpet") 를 바로 띄운다.** 설정은 두 번째 app 이다.
HG-T113-S3 는 app 섹션 + 링커 심볼로 훑지만, 여기서는 모듈과 같이 constructor 가 `launcherAddApp()` 으로 등록한다 ([11](11-project-skeleton.md) 4 절).

## 3. 폰트

목업의 **Jua**(한글 본문)와 **Silkscreen**(시계 · 숫자 픽셀 폰트) 그대로다. 둘 다 OFL.

- **Tiny TTF 로 실행 중에 그린다.** HG-T113-S3 가 FreeType 으로 D2Coding 을 그리는 것과 같은 방식이다. `lv_font_conv`(node)로 미리 변환할 필요가 없고 크기를 마음대로 만든다
- (종류, 크기) 마다 한 번 만들어 둔다. 글리프 캐시 256 자
- **fonts 파티션**에 따로 둔다 (5 절)

### 막혔던 것

| 증상 | 원인 | 해결 |
|---|---|---|
| `…` `·` 가 안 나온다 | **Jua 에 U+2026, U+00B7 이 없다** (cmap 확인). stm32h7-gfx 13 편의 `·` 와 같은 종류 | Jua 의 fallback 을 같은 크기 Silkscreen 으로. 반대 방향은 걸지 않는다 — 서로 물리면 둘 다 없는 글자에서 끝없이 돈다 |
| 가운데 정렬한 글자가 위로 뜬다 (18 px 에서 약 3.5 px) | Tiny TTF 는 줄 높이 = ascent − descent + **line gap**, 기준선은 line gap 을 모두 아래에 붙인다. Jua 는 line gap 이 250 / 1000 | 줄 상자의 중심이 글자 중심에 오게 다시 잡는다 — Jua 높이 1.10 em · 기준선 0.18 em, Silkscreen 1.00 · 0.19 |
| 같은 24 px 인데 날짜가 시계보다 커 보인다 | Silkscreen 글자 높이는 0.62 em, Jua 한글은 약 0.8 em | 시계 Silkscreen 28, 날짜 Jua 16, 바닥선을 맞춘다 |
| `12m` 이 `12M` 으로 | Silkscreen 은 대문자 전용 | 목업도 같다. 그대로 |

### 글자 크기 3 단계

보통 100 / **크게 115 (기본)** / 아주 크게 130 %. `uiFont(size)` 가 비율을 곱해 만든다. NVS `font` 에 저장.
화면이 800 × 480 고정이라, 카드는 하나씩 넣어 보고 패널 밖으로 넘치면 빼고 "+N건 더 있어요" 로 센다. 큰 글자에서 날짜는 `10/10 (토)` 로 줄인다.

## 4. 답답이 (pet.c)

로고 심볼을 부품별 LVGL 객체로 나눠 상태마다 보이고 숨기고 움직인다. 좌표는 목업 SVG (viewBox −20 −15 330 320 → 210 × 204) 그대로.

| 상태 | 표정 | 움직임 |
|---|---|---|
| 여유 | 동그란 눈 + 웃는 곡선 (∩), 볼터치 | 입 막대 숨쉬기 ±4 px, 2 초 (인계 문서) |
| 배고픔 | 동그란 눈 + 눈동자, 벌린 입과 혀 | 눈동자 두리번, 땀방울이 몸 옆을 따라 흘러내림, 발 동동 |
| 울음 | 탁한 초록 몸, 가는 선 눈, 눈물 줄기, 찡그린 입 | 흐느낌 (들썩임), 눈물방울이 발 앞으로, 물웅덩이 |
| 냠냠 | 반원 눈 (^^), 볼터치, 오물거리는 입 | 김밥을 4 초 동안 다섯 입에 베어 먹는다 |

- 반원(눈 · 발)은 반원 높이만 한 상자가 원을 잘라 보이게 한다
- 땀방울은 그리기 이벤트(삼각형 + 원), 찡그린 입 · 웃는 눈은 `lv_line` (베지어 · 원호 점)
- **김밥은 ARGB8888 캔버스**에 한 번 그리고, 한 입마다 둥근 자리(큰 원 + 이빨 자국 작은 원 둘)를 투명하게 지운다. 뒤가 몸이든 바탕이든 자연스럽다. 모서리는 작은 삼각형을 굵기 2R · 둥근 끝 선으로 부풀려 둥글게
- **app 을 다시 들어오면 (글자 크기 변경, 설정에서 돌아옴) 캐릭터를 새로 만든다.** 처음에는 `pet.c` 가 이전 상태를 기억해
  `petSetState()` 가 "같은 상태" 라며 돌아가서 **모든 표정 부품이 한꺼번에 보였다.** 새로 만들 때 상태를 잊고, 김밥 캔버스 버퍼(약 26 KB)도 푼다
  (설정 ↔ Ping Pet 세 번 오간 뒤 PSRAM 남은 양 그대로)
- 목업과 다르게 한 것 : 냠냠 입을 몸 가운데로 (목업은 12 왼쪽), 여유 눈을 ^^ 에서 웃는 곡선으로, 김밥 모서리를 둥글게 (사용자 요청)

## 5. 폰트 파티션 · 굽기

폰트를 앱에 넣으니 앱이 **3 MB** 가 되고 USB-OTG 다운로드에서 압축 쓰기가 멈췄다.

```
A fatal error occurred: Failed to write compressed data to flash after seq 575 (result was C900: Too much data)
```

| | |
|---|---|
| 압축 없이 쓰기 | 된다. 다만 3 MB 에 27 초 (USB-OTG ROM 다운로드가 약 100 KB/s. 압축해도 빨라지지 않았다 — 846 KB 압축 8.4 s, 무압축 7.6 s) |
| **폰트를 fonts 파티션으로** | `data 0x40`, 0x810000, 3 MB. `tools/fonts.py` 가 TTF 를 묶고(이름 · 위치 · 크기 · CRC 표), 부팅할 때 `esp_partition_mmap` 해서 이름으로 찾는다 |

앱 3.0 MB → **846 KB**, 평소 굽기 36 → **17 초**. 폰트는 바뀔 때만 `flash.py --fonts` (34 초). 폰트 파티션이 비어 있으면 로그를 남기고 Montserrat 로 뜬다.

## 6. 데모 모드 · 설정 · CLI

### 데모 모드

가상의 메시지로 여유 (8 s) → 배고픔 (8 s) → 울음 (가상 시계 +26 분, 8 s) → 냠냠 (5 s) → 나머지에 차례로 답장 (6 s) 을 돈다.
맥이 시각을 줬으면 그 시각, 아니면 2026-10-10 14:05 KST. 상단 바에 `DEMO`. 설정 앱이나 `demo on|off`.

### 설정 앱

Ping Pet 상단 바를 **길게 누르면** 열린다. 글자 크기, 밝기 (10 ~ 100 %, 손을 떼면 저장), 데모 모드, 버전 · 시리얼.

### CLI

| 명령 | |
|---|---|
| `demo on` / `off` / `info` | 데모 모드 |
| `inbox info` / `clear` | 목록 · 상태 · 배부름 |
| `ui info`, `ui app pingpet\|settings`, `ui font 0~2` | 화면 전환, 글자 크기 |
| `lcd capture` | 화면 캡처 → `python3 tools/capture.py -o shot.png` |

**캡처**는 지금 표시 중인 프레임버퍼를 CDC 로 보내 PNG 로 만든다 (1.6 초). 처음에는 갱신 중에 읽어 **두 프레임이 섞였다** (숨쉬기 중인 입 막대가 어긋나 보였다). 캡처하는 동안 화면 갱신을 멈추고, 재개하면 한 번 전체를 다시 돌린다.
